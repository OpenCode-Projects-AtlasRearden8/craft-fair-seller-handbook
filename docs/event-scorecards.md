# Event Scorecards

Printable, pencil-grade verdict forms. One pile, one pencil, honest
numbers — the whole point of a scorecard is that it's filled while
the day is still telling the truth. The setups stem from the
[chapters](index.md); the scoring happens [same-night](09-after-event-review.md).

## Scorecard A: the free-visit scout card

Fill it in while wandering, as a *shopper*, before you ever pay a
booth fee. These notes go home into the final scorecard when you
book (see [Finding the Right Events](01-finding-events.md)).

```text
EVENT SCOUT CARD — not an application, just eyes
EVENT: ______________________________ DATE: ___________
LOCATION: ___________________________  INDOOR / OUTDOOR / COVERED

WHO SHOPS HERE (three kinds of people you saw):
  1. ____________________________
  2. ____________________________
  3. ____________________________

WHAT SELLS (crowd seemed around):
  _________________________________
  _________________________________

TABLES AT THE EVENT: ______   AISLE CROWD (1-5): ______
DO SHOPPERS CARRY BAGS?  Y / N

ASKED THREE VENDORS:
  would they return? _______   fee ballpark? $_______
  one honest summary: ______________________________________

MY STUFF COULD SELL HERE?  (1-5): ____  WHY:
  ______________________________________________________

SCOUT VERDICT:  BOOK / WATCH ANOTHER YEAR / PASS
```

## Scorecard B: the post-event verdict

The one-page [after-event ritual](09-after-event-review.md)
companion. Fill numbers 1-5, where **1 = poor, 3 = fine, 5 =
excellent**:

| Question | Your 1-5 |
| --- | --- |
| 1. Traffic quality (people passed ALL day, not just once) | |
| 2. Shopper fit (did the *right kind* of buyer reach you?) | |
| 3. Cost-to-value (was the booth fee worth what happened?) | |
| 4. Organizer quality (answered questions, helpful, honest) | |
| 5. Neighbor vendors (community: collaborators, not competitors) | |
| 6. Your setup's survival (did the booth work here — size, power, light) | |
| 7. Weather luck (cooperated, or you had the plan) | |
| 8. Table presence (tables stayed stocked, priced, appealing) | |
| 9. Money margin-of-day (> 0, and near your goal) | |
| 10. Would I return, with what I know now | |

Ten rows, one pencil, five minutes.

**Reading the verdict:**

- **8-10 overall**: return
  as-is next season, book early (the returning-vendor list is
  worth its weight in good spots).
- **6-7**: return
  *with one change*, decided by the change list.
- **4-5**: watch this event another
  season; rebook only if something on *their* side changed.
- **Under 4**: pass, pleasantly.

## The event decision matrix (fast version)

For the week before the season, when offers stack up and you start
booked-silly:

| Question | Why it matters |
| --- | --- |
| **Shopper fit?** | The right kind of buyer beats a big crowd. |
| **Cost all-in vs expected gross?** | Know your [cost per $100](09-after-event-review.md) floor before saying yes. |
| **Day of week?** | Saturday beats weekday for gifts; weekdays are for food. |
| **Is power available?** | If my booth needs it, it decides for me. |
| **Is it a return-to-market that earned a spot?** | Returning beats "new exciting thing" slightly less than half the time. |
| **Does the event refund for weather?** | Read the [vendor contract](02-applications-and-permits.md) again; this clause decides more days than you'd think. |
| **Can I get there, set up, and rest before the next day?** | Two events back-to-back is a strategy; two badly-rested events is a mistake. |

## The wet go/no-go rule (write it BEFORE the season)

Because deciding in a panic is deciding badly. Fill this in once,
in pencil, before you book your first spring event:

```text
MY WET/WEATHER CALL PAPER (written in sunny weather)

SAFETY SAYS STOP WHEN:
  [ ] forecast thunder/lightning within booth hours
  [ ] sustained winds above ~____ mph (my canopy's honest rating)
  [ ] named storm / official severe watch that overlaps load-in

MONEY SAYS STOP WHEN:
  [ ] the vendor contract lets me drop without paying the fee
  [ ] the event officially cancels first
  [ ] I'd rather save the stock than the fee (circle: yes / no)

MY CALL IS MADE AT ____ (time) BY CALLING _______ (organizer contact)

SEASON'S TOTALS AT THE BOTTOM (fill in over the year):
  wet-ish events gone to: ______   no-gos instead: ______
```

## Scorecard C: the season roll-up card

A single card per season — the top strip of
your [weekly roll-up](06-honest-sales-tracking.md), plus the
bookings verdict. Pin it inside your cash-box lid or tape it to the
van-window year.

```text
SEASON: ________________ (dates)

EVENT                        GROSS   MARGIN   SCORE (1-5)  RETURN?
  _________________________   _____   _____    ____         Y/N/change
  _________________________   _____   _____    ____         Y/N/change
  _________________________   _____   _____    ____         Y/N/change
  _________________________   _____   _____    ____         Y/N/change

TOTAL MARGIN: $_______   BEST EVENT: _______________
COST PER $100 (avg): $____   WORST EVENT: ________________

NEXT SEASON'S BOOKING NOTES (three lines, tops):
  1. ___________________________________________
  2. ___________________________________________
  3. ___________________________________________

MY ONE BIG SEASON CHANGE FOR NEXT YEAR:
  ____________________________________________________
```

## Honest scoring is the whole tool

Two known failure modes, both worth naming:

- **Inflating a number out of guilt.** Giving a 4 because you met
  the organizer's kid turns January's booking decision into a
  waste. The scores aren't about anyone's feelings; they're data,
  and they're allowed to be disappointing.
- **Scoring from memory.** The scorecard is worth less each day
  past the event; same evening or not at all. (See the
  two-minute fallback in the [ritual chapter](09-after-event-review.md)
  for days when thirty minutes isn't in you.)

If your numbers *ever* deviate wildly from your dollars, believe
the dollars: gross, margin, and cost-per-$100 are the ground truth,
and the scorecard is the steering wheel on top of it.
